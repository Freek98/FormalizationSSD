The goal of this repository is to formalize the SSD paper (https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.TYPES.2024.3). 

In order to typecheck, one must be on the cubical agda branch of https://github.com/agda/cubical/pull/1297

Matching to the paper: 
- Definition 1.2 is called is-countable 
- Definition 1.3 is called is-countably-presented 
- Remark 1.4 is called is-countably-presented-equivalence

Parts of the work have been done with an AI, see also https://github.com/Freek98/AutoFormalizationSetup and LLMInteraction.md. At some point, everything here has been at least skimmed by a human. If I've skimmed over significant portions of the file, it should say so at the top of the file.
