This project has been worked on for some time without an LLM. Then Josef Urban set us up with a Claude subscription and explained his approach to autoformalization, later we took over the subscription.

We fed it some markdown instructions, the paper and a version of this project. With this, the LLM created a lot of code (a full history is in https://github.com/Freek98/AutoFormalizationSetup). Some of it was useful and snippets were copied to this directory.

However, it was not manageable (or fun) to carefully read all the output of the LLM. For the LLPO result, a more interactive approach was taken, where I tried to explain the LLM the structure the proof should have and what results should be used from work it had already done in the autoformalization. Then I tried to have a "conversation" about cleaning up and refactoring parts of the proof. Two parts are currently temporary fixes I'd like improve upon with a more elegant proof. These are both in LLMGeneratedFixes, and the tops of the files explain in what sense they are not elegant, and what their elegant replacement would look like.
